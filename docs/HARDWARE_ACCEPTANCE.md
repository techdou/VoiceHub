# 真机验收清单（需小米遥控器 + VB-CABLE 实机）

模拟器页已覆盖无硬件可验证的部分（映射分发、音频管线、Provider 触发、统计）。
以下各项需豆哥拿到遥控器后逐项执行。每项标注了出问题时优先查看的位置。

## 准备

- [ ] Windows 蓝牙设置中能发现并配对遥控器（RC001 / RC003 / MI RC）
- [ ] VB-CABLE 已安装，声音设置里出现 CABLE Input / CABLE Output
- [ ] 微信输入法语音快捷键已设为 Ctrl+Win，录音设备 = CABLE Output

## 连接

- [ ] 声桥"连接"页能列出已配对遥控器（自检页"遥控器配对"= 正常）
- [ ] 选中后状态走完 连接中 → 初始化语音通道 → 已连接
- [ ] 状态卡片显示型号与电量（无电量不阻塞，仅少一项）
- [ ] 关闭声桥窗口 → 托盘常驻；托盘"显示设置"能唤回窗口

## 语音

- [ ] 按住遥控器语音键：状态指示进入"语音中"，说话有电平跳动
- [ ] 微信输入法被自动唤起并开始听写（CABLE Output 收音）
- [ ] 松开语音键：约 0.2s 内听写收尾，文字落在聚焦输入框
- [ ] 连续两次快速会话无串音（代际隔离）
- [ ] 按 55–60 秒固件自动断流（RC003 固件边界）：会话正常收尾、可再次发起
- [ ] 中途走远断连：状态 → 重连中；回来自动恢复（指数退避，最长 30s）
- [ ] 系统睡眠再唤醒：自动重连恢复语音
- [ ] 连续失败多次后蓝牙无线电自愈触发（日志可见 radio_cycles 增长）
- [ ] 真实键盘按 F5：浏览器刷新正常（吞键闸不误伤）
- [ ] 按住遥控器语音键期间 F5 不触发浏览器刷新（吞键闸生效）

## 按键

- [ ] 方向键 / OK / 返回 / 主页默认映射生效（↑↓←→、Enter、后退、无）
- [ ] 任意按键改绑（如 OK → Ctrl+Enter）立即生效
- [ ] OK / 主页 / 菜单 / TV 双击与长按二级动作生效
- [ ] 录制自定义快捷键（如 Ctrl+Shift+K）并绑定生效
- [ ] 打开应用 / 打开网页动作生效
- [ ] 截图（区域 / 全屏）动作生效
- [ ] 按住方向键连发生效；粘贴/复制类不连发

## Profiles

- [ ] 新建方案、切换方案生效
- [ ] Smart Profiles 开启后：前台切到绑定应用自动换方案，切走回退
- [ ] 方案导入的设置在重启后保留（settings.json 原子写）

## 统计与历史

- [ ] 按键 / 语音计数即时累加，重启后仍在
- [ ] 历史页记录时间 / 时长 / 前台应用 / 方案；清空生效

## 日志与排查

- 日志：`%APPDATA%\app.soundbridge.windows\logs\soundbridge-YYYYMMDD.log`
- 设置：同目录 `settings.json`（含 .bak）
- 自检页"打开日志目录"
